###### Назначение файлов

* ###### `make\_test\_data.py` — создаёт тестовые данные трёх отделов гостиницы: `reception`, `rooms`, `restaurant`. В каждом отделе создаётся по 4 CSV-файла, всего 12 файлов.
* ###### `backup.py` — создаёт полные резервные копии в формате TAR.GZ, записывает JSON-манифесты с SHA-256, выполняет ротацию (оставляет 6 последних копий), проверяет восстановление и позволяет восстановить последнюю копию.
* ###### `rpo\_rto.md` — расчёт показателей RPO и RTO для гостиницы по варианту 16.

###### Требования

###### Python 3.12 или новее. Используются только стандартные библиотеки Python.

###### Запуск

###### Откройте терминал в папке `practice1` и выполните:

```powershell
python make\_test\_data.py
python backup.py
```
---

###### Команда `python backup.py` создаёт очередную копию, выполняет ротацию и проверяет восстановление во временную папку.

###### Чтобы отдельно проверить последнюю резервную копию (например, после изменения JSON-манифеста), выполните:

```powershell
python backup.py verify
```
---

###### Чтобы восстановить последнюю резервную копию, выполните:

```powershell
python backup.py restore
```
